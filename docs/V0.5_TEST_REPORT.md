## 滑动性能：结构优化已完成，卡顿尚未确认彻底解决

本版从 V0.4 的多个混合状态 UI 改为单个按分类展平的带稳定 key / contentType 的 `LazyColumn`，不在滑动期间网络访问、解析长 README 或加载图片；README 摘要仅在用户主动打开详情时渲染。下载状态仍按整数百分比更新。

`dumpsys gfxinfo` 测试结果：

| 指标 | Android 11 | Android 15 |
| --- | ---: | ---: |
| 帧数 | 206 | 106 |
| Janky 帧 | 196（95.15%） | 88（83.02%） |
| 第 50 百分位帧耗时 | 61 ms | 61 ms |
| 第 90 百分位帧耗时 | 93 ms | 89 ms |

**不能据此宣称已消除卡顿。** 模拟器采用软件 GPU + Debug 构建，上述指标受 CI 环境影响大，不代表 ARM64 真机表现。V0.4 与 V0.5 脚本采样的操作和帧数亦不一致，不适合直接做性能改善百分比比较。后续需以真机 Release、Macrobenchmark、JankStats 或 Perfetto 做可复现的定量分析。

## 测试范围限制

- 未在真实中国大陆运营商网络对每个镜像做持续吞吐或断流测试；测速入口可用不等于所有镜像始终可达。
- 未下载并安装全部 15 项；osu! APK 超过 500 MB，只核对了上游发布文件及新版容量逻辑；DroidDeck 多 APK 变体通过专用名称规则选取，尚未真机安装验收。
- DirtyFrag、KSuRoot、GhostLock 保持仅外部项目入口的安全设计。
- DroidDeck 官方明确要求受支持的 Adreno GPU；**MTK/Mali 不支持**，目录可见不代表硬件兼容。
- 尚未验证 Android 自更新覆盖签名、HTTP/SOCKS5 端到端代理转发、ARM64 真机和全部系统权限场景。
- 此为 V0.5 **开发版**。GitHub 最新公开 Release 仍为 V0.4.0，未自动升级 Latest。
