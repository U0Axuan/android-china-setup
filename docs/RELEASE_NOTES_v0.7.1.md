# Android China Setup v0.7.1 · 图标准确性、README 阅读体验与 Material 3 修复

## 本次改进

- **Logo 核验**：删除原来“取 README 第一张图片”算法。优先读取人工核对的原作者 GitHub 仓库相对路径（`logoPath`），客户端验证实际文件、大小与来源后显示。未验证、无原始图标或加载失败时不展示任何伪造图标或首字母占位。
- **更严格的目录审计**：`tools/logo_audit.py` 在目录变更时检查图片身份、格式、容量、长宽比例；徽章、长横幅和截图不能冒充 Logo。
- **README 阅读体验**：使用 CommonMark 和 jsoup 转换原作者 README，按标题、段落、列表、引用、代码块排版，过滤 HTML 布局标签、JS/脚本、图片和状态徽章。支持正文选择复制，长文使用分块惰性加载；始终保留原作者完整 README 链接。
- **Material 3 适配**：统一字体层级与色彩 token；移除设置页不合理的 420dp 留白和重复的标题/返回按钮，代理设置移至易操作位置。返回箭头和系统返回键遵循同一层级规则。
- **缓存正确性**：失效老版错误图标缓存；云析改用官方轻量启动图标；目录更新修改图标路径时及时失效旧图。
- **测试**：为 Markdown 清理、列表/代码渲染、非法图标路径补充单元测试；Android 11 与 Android 15 模拟器测试与固定签名证书一致性检查。

## 兼容性与升级

- Android 11 及以上；`versionName = 0.7.1`、`versionCode = 8`。
- 继续使用与 v0.7.0 一致的正式签名，允许覆盖安装，无需清除应用数据。
- 其余应用目录、下载校验、镜像策略与 GitHub Issue 推荐入口均保持兼容。

## 说明

无法核实的应用 Logo 默认隐藏。这并非缺图错误，而是避免误导用户的设计决定。应用内 README 为安全清理后的阅读版，完整原始 HTML/Markdown 的效果请通过“阅读原项目 README 全文”前往原作者仓库查看。
