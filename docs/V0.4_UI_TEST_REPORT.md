## 帧率与滑动：尚不能宣称问题彻底解决

UI 已从同一个混合布局重构为四个独立页面，并使用带稳定 key 的 `LazyColumn` 和下载进度节流。Android 模拟器的 `dumpsys gfxinfo` 仍报告极高掉帧：

- Android 11，**92/93 帧 Janky（98.92%）**，50 分位 61ms；
- Android 15，**32/33 帧 Janky（96.97%）**，50 分位 77ms。

这两组数来自 GitHub 云端 x86_64 / `swiftshader_indirect` **软件 GPU 渲染的 Debug APK**，与实际 ARM64 手机上的硬件 GPU 性能不可直接等同。基于这些数据，**无法确认滑动卡顿已经彻底消失**。需在 ARM64 真机运行 Release/稳定签名构建并使用 Macrobenchmark、JankStats/Perfetto 复测，定位 UI 帧超时、GPU 绘制和应用后台网络任务的影响。
