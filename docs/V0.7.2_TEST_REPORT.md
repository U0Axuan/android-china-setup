## 明确的覆盖边界

- 模拟器为 x86_64 Pixel 6 配置、软件 GPU；尺寸切换并不等同于所有平板、折叠屏或厂商 ROM。未做实体 ARM 手机验收。
- 未进行 TalkBack 人工听读、真实手势操作或整机耗电/温升测试。不能声称全部无障碍标准或所有设计规范已认证。
- 软件渲染模拟器采集到明显帧延迟，不能据此判定真机性能，也不能声称已达到 60fps；frame_stats 已随结果保留。
- CodeQL 当前运行 Python/Actions；本次 Kotlin 静态检查由 Android Lint 完成，不把它表述为 Java/Kotlin CodeQL 全量扫描。
- 目录资格审计仍会对许可证、维护活跃度、公开安全扫描证据不足的第三方项目输出提醒，按既定规则不阻止目录通过；目录校验通过不代表所有收录应用均已通过安全认证。
- Lint 六条警告：目标 API 版本、Compose BOM/Activity/Core 依赖更新建议、Android 12+ dataExtractionRules 建议、minSdk 30 下多余的 v26 资源目录。补丁不迁移框架大版本。
