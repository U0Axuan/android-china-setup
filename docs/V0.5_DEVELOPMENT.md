# V0.5 开发任务说明

这次更新包括：15 项应用（新增 DroidDeck、osu!、DirtyFrag、KSuRoot）、6 个分类、每项一句话简介及离线 README 快照，去掉复选框与底部导航；右上角进入统一设置（测速、代理、关于、自更新）。

## 滑动性能改造
- 使用一个按分类展平的 `LazyColumn`，稳定的项目 key / contentType，不在列表里请求网络或 Markdown 图片
- README 快照只在用户点击详情后显示，静态内置于 `apps.json`
- 下载进度按整百分比刷新，避免高频状态修改
- 保留 Android 11/15 的云端滑动与 UI 层级测试和 `dumpsys gfxinfo` 原始帧统计
- 云端软件 GPU 的掉帧不能直接代表 ARM64 真机；后续需使用 Release + Macrobenchmark 验证

## 风险与下载
- DroidDeck 使用 `Droid-Deck/DroidDeck`（本地 Steam，非另一个同名 Stream Deck 控制面板项目）；需要支持的 Adreno GPU，MTK/Mali 不在官方支持范围
- osu! 使用 `ppy/osu` 的安卓官方 APK；因 APK 体积可超过 500 MB，将单文件上限调为 1GB，并在下载前核对存储空间
- DroidDeck 的 APK 发布可能包含多种分发变体，通过受控的文件名规则选取标准 APK，不猜测第一个文件
- DirtyFrag（`mitschud/DirtyFrag`）、KSuRoot（`hmascs/KSuRoot`）与 GhostLock 均不提供本地提权自动执行
- README 快照是人工整理的离线摘要，可能过期；提供直达原作者 README 的链接

## 发布
V0.5 先以开发版提交和云端构建测试，不自动覆盖已发布的 GitHub Latest V0.4。稳定发布须另行升级版本并确保兼容签名与实际下载测试。
